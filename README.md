# 🐾 Тамагочи - Telegram Mini App

Виртуальный питомец с системой уровней, магазином и реферальной системой.

## 🎮 Функции

- 🐣 Живой питомец с 4 характеристиками
- 🛒 Магазин с предметами
- ⬆️ Система уровней
- 🪙 Две валюты (монеты и алмазы)
- 👥 Реферальная система
- 🏆 Глобальный рейтинг
- 🛡️ Защита от читов
- ☁️ Облачное сохранение
- 📱 Адаптивный дизайн
- 🌓 Темная тема
