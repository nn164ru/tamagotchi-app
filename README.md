# 🐾 Тамагочи - Telegram Mini App

Виртуальный питомец с системой уровней, магазином и реферальной системой.

## 🚀 Установка

1. Склонируйте репозиторий
2. Замените настройки в `config.js`
3. Загрузите на хостинг (GitHub Pages, Netlify и т.д.)
4. Настройте бота в Telegram

## 📁 Структура

- `index.html` - Главная страница
- `style.css` - Все стили
- `app.js` - Основная логика
- `security.js` - Система защиты
- `database.js` - Работа с Supabase
- `config.js` - Конфигурация
- `manifest.json` - PWA

## 🔧 Настройка

1. Создайте проект в Supabase
2. Создайте таблицу `players`
3. Замените `SUPABASE_URL` и `SUPABASE_KEY`
4. Замените `BOT_USERNAME`

## 🎮 Функции

- 🐣 Живой питомец с 4 характеристиками
- 🛒 Магазин с предметами
- ⬆️ Система уровней
- 🪙 Две валюты (монеты и алмазы)
- 👥 Реферальная система
- 🏆 Глобальный рейтинг
- 🛡️ Защита от читов
- ☁️ Облачное сохранение
- 📱 Адаптивный дизайн
- 🌓 Темная тема
